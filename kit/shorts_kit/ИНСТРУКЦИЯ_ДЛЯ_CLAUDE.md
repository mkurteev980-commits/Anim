# Набор для кукольных шортсов («Балкон», «Зорька»)

## Как пользоваться (для человека)
1. Открой новый чат с Claude (Claude Code в облаке или чат с загрузкой файлов).
2. Прикрепи этот архив `shorts_kit.zip`.
3. Напиши, например:
   - «Сделай вторую серию Зорьки по этому набору, 50 секунд, концовка — монетка»
   - «Новая история в этом стиле: …(сюжет)… Голос Prince Nur через ElevenLabs»
4. Claude прочитает этот файл и соберёт видео тем же способом.

---

## Для Claude: как устроен набор и как делать видео

Итог всегда — MP4 1080×1920 30 fps (плюс HTML-исходник). Пользователь работает с телефона.

### Шаблоны (`shablony/`)
Каждый HTML — автономный движок на Canvas 2D: персонажи на кукольном риге, фоны, субтитры, сцены, плеер.
`?t=12.3&ui=0` показывает один кадр без панели.
- `01_osnovnoy_dvizhok_svet_lipsink.html` — **самый полный движок, бери за основу**:
  - риг: длинные конечности (`KIND.*.ua/fa/th/sh`), крупные кисти (`hs`), поворот 3/4 (`turn: 1 | -1`), дальние конечности темнее;
  - мимика: веки `lids:[л,п]`, прищур `low`, асимметричные брови `brows:[[внеш,внутр],[внеш,внутр]]`, морщины `wrinkle`, размер глаз `eyeS`, зрачки `irisS`;
  - рты: `smile, worried, scared, oh, shout (с зубами), clench, grin, flat, talk, whistle, lip` (`lip` — липсинк по массиву `LIP`);
  - вторичная анимация: `sway` (косички/банты), `flut` (галстук), `swing` (свисток);
  - свет: `litPerson(o,{shadow,rim,shade})` — тень, контровой свет, объём; `lightPass([...источники], тьма)` — тьма + конус фонаря/пятна; `grade(цвет, сила, режим)` — цветокор;
  - глубина резкости: `bbg(key, fn, blurPx)` — размытые кешированные слои;
  - камера: `cam(z, fx, fy)` + `hand_held(t, амплитуда)`;
  - позы: `runPose`, `walkPose`; сцены — массив `SCENES` ({t0, draw, ui, wh (вжух), vig, subY}).
- `02` — анимированная концовка «Монетка».
- `03` — концовки «Развилка (таймер 3-2-1)», «Две двери», «Четвёртая стена» + `cta()` «ПИШИ 1 ИЛИ 2».
- `04` — статичные идеи концовок: карта, записка, монетка, полароиды, две тени, рация.
- `05` — захват руки и перетягивание (тайминг с замахом/перехлёстом через `kf()`).
- `06` — бег с параллаксом (`scroll()`, слои far/mid/ground/fg).
- `07`, `08` — готовые серии «Зорька 1» и «Балкон 2» (полный пример структуры серии ~50 с).

### Как собрать новое видео
1. Скопируй `01_…html`, замени `SUBS_RAW`, `DUR`, сцены и `SCENES` (движок не трогай).
2. Проверка кадров: тестовая копия без Google Fonts
   `grep -v 'fonts.g' index.html | sed "s/Montserrat/Inter/g" > test.html`,
   скриншоты: `google-chrome --headless=new --no-sandbox --disable-gpu --hide-scrollbars --window-size=540,960 --virtual-time-budget=1200 --screenshot=f.png "file:///…/test.html?t=T&ui=0"`.
   Склей 8 кадров `ffmpeg … xstack` и посмотри: лица не в полосе субтитров (по умолчанию Y≈1240, можно `subY` у сцены), руки не на лицах, главное в кадре одно.
3. Рендер: Chrome с `--remote-debugging-port=9333 --window-size=1080,1920` на `render.html?t=0&ui=0`, затем
   `node skripty/render.mjs <папка> <длительность_сек>` → `frames/f%05d.jpg`.
4. Звук: примеры в `primery_zvuka/` (numpy): шаги в такт ходьбе, сверчки, сердцебиение, нарастание, бас-удар, звон монеты, вжух. Сведение с голосом и `ffmpeg -framerate 30 -i frames/f%05d.jpg -i mix.wav -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -shortest out.mp4`.

### Голоса (ElevenLabs, через коннектор)
- Диктор: **Prince Nur** — `oKxkBkm5a8Bmrd1Whf2c`
- Бабушка: **Babushka Valya** — `ZgfahluxUmUzBjjL81NN`
- Вожатый Гена: **Alexey I** — `gRp20jh5cr1dR3Lhhapi`
- Модель `eleven_v4`, теги эмоций в квадратных скобках: `[whispering]`, `[low, tense]`, `[sing-song, creepy]`.
- Для скачивания нужен разрешённый хост `elevenlabsusercontent.com`.
- Тайминг: паузы через `ffmpeg silencedetect` или транскрипция с пословными таймкодами; фразы ставятся на время субтитров (`rasstanovka_ozvuchki_po_taymkodam.py`).
- Липсинк: RMS голоса персонажа по кадрам (30 fps) → массив `LIP` в HTML, рот `mouth:'lip'`.

### Правила стиля, которые понравились пользователю
- Без начальной заставки — сразу хук.
- Крупные/средние планы, персонаж почти на весь кадр, сильные позы, движение.
- Свет фонаря/луны, тени, контровой свет, размытый фон, цвет под настроение, ручная камера.
- Иерархия: фон тише героя, одна главная точка внимания в кадре, эффекты по делу.
- В конце — интерактивный выбор (монетка / развилка с таймером / две двери / четвёртая стена / две тени / карта) + «ПИШИ 1 ИЛИ 2».
- Шрифты: Montserrat 900 (в MP4 — Inter), субтитры-караоке с красными «опасными» словами (`*слово`).

### Персонажи
- «Балкон»: мальчик в полосатой пижаме, мужчина в сером пальто, баба Валя (её сын — убийца), красный сапог.
